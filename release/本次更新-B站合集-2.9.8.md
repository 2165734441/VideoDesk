# 映格 · VideoDesk 2.9.8

Windows 本地视频处理工作台。2.9.8 把最近的 B 站合集录制和素材库增强合并进正式安装包。

## 这个版本下载哪个

| 文件 | 给谁 | 说明 |
| --- | --- | --- |
| `VideoDesk-2.9.8-Windows-x64.exe` | Windows 10 / 11 x64 电脑 | 双击安装，内置运行时，不用另装 Python 或 Node |
| `VideoDesk-Android-1.8.0.apk` | Android 10 及以上手机 | 手机伴侣，versionName 1.8.0 / versionCode 27 |

## 本次更新

**B 站多 P / 合集一起录。** 在下载页粘贴 B 站合集或多 P 链接，点「读取目录」列出全部分集，勾选后逐集加入下载队列；每集单独保存原视频和元数据，不需要再手动复制 17 个分 P 链接。实测 17 集合集全部保存成功，总计 319.2 MB。

**素材库增强。** 加入跨视频检索库（`library-index.sqlite`）、素材分类与筛选、视频增强、定时转换和备份；素材卡片对 B 站「父标题 + pNN + 分集标题」显示短标题，避免超长卡片挤在一起。

**采集与界面。** 主页 @ 账号读取、关键词一键批量抓取并生成 AI 包、深色侧栏和新版工作台样式继续保留；采集清单仍然支持「直接下载视频 / 每期 AI 包 / 合并 AI 包」三种方式。

**手机伴侣 1.8.0。** 支持手机回放上传后删除，继续支持多主播检测和录制；安装包使用同一签名覆盖升级，手机上的数据保留。

## 安装与兼容

- Windows 安装包会安装到 `%LOCALAPPDATA%\VideoDesk` 并启动托盘服务。**不要从终端直接启动 EXE**，以免被系统回收；装好后从开始菜单或托盘打开。
- 如果电脑上已有正在录制/监听的 2.9.5 服务，安装前先在托盘退出旧服务，并备份 `VideoDesk-Storage\Desktop\data` 数据目录；安装新版本不会删除数据，但会切换运行目录。
- Android 手机需开启 USB 调试，USB 连接方式选「传输文件」；电脑端通过「手机伴侣」连接。

## 校验

`VideoDesk-2.9.8-SHA256SUMS.txt` 内含 EXE、构建记录和 Android APK 的 SHA256；`VideoDesk-2.9.8-build.json` 记录构建文件数和 payload 哈希。

## 已知限制

- B 站公开合集在免登录下载时最稳定；带浏览器 Cookie 下载个别分 P 可能因签名地址失效而失败，失败后可在素材库重试。
- 直接下载清晰度取决于平台当前给游客/登录账号的可用流；需要更高清晰度时先在对应平台登录。
- 视频采样、OCR 与语音转写可能漏掉短暂动作或文字，结果需要自行核对。
