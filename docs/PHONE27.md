# 映格 2.7 手机伴侣

这是 2.7 的历史说明。2.8.0 / 手机 1.1.0 的独立多主播录制和 USB 自动回放导入见 [新版说明](PHONE28.md)，以下手机单路屏幕录制作为备用方式保留。

电脑端「直播录播与回放」中可安装／更新 Android 手机伴侣。连接 USB、允许 USB 调试后，点击连接；本机通过 ADB 的 USB 反向端口与手机配对，接口仅监听电脑回环地址，没有局域网公开端口。断开 USB 后，手机不能通知电脑。

添加主播时填主播主页、直播间或抖音直播分享链接。备注名选填，空白时会在读取到可靠主播信息后补入昵称；昵称可能重名，不能单独定位主播。从关注列表选择时不必再次填写链接。关注人数仅统计普通网页实际返回的关注用户，显示已读取数量和已知账号总数；未观察到首页、末页或数量不符时显示未确认完整，不承诺平台隐藏／失效账号可以导入。

手机用法：

1. 在电脑保存主播，选择「手机伴侣」检测、开播后「通知电脑，由我选择」「由电脑录制」或「由手机录制」。在手机点「与电脑同步」。也可在手机粘贴分享链接保存，断开时保留为待同步主播。
2. 网页检测需要伴侣保持前台，可轮流检查多位主播；手机录制时暂停切换。检测不到可靠状态时提示未知，不视作正在直播或未开播。
3. 可选「抖音开播通知」在系统中手动开启通知读取权限。伴侣只处理抖音的开播通知；昵称匹配通知需要先确认主播与直播画面，再决定录制，不凭重名通知自动开始。
4. 电脑显示手机开播通知，可选择电脑录制、手机录制或忽略。电脑直接保存直播流，支持多路；手机录制当前屏幕，一台手机同时只能录一路。
5. 选择「手机录制」后，伴侣先读取并核对真实房间编号，再请求 Android 录屏授权。选择整个屏幕并确认开始；录屏启动后会打开所选主播的抖音直播间。手机系统若询问是否打开抖音，请允许。未取得可靠编号时不会开始录制，可改用「录制当前画面」后自行切到抖音播放。停止时回伴侣点「停止并保存」，或从录制通知停止；电脑连接时也可点「停止手机录制」。
6. 手机录制保存到手机 `Movies/VideoDesk`，可从「手机回放」或系统相册播放；不会自动上传电脑。声音通过 Android 内部播放音频捕获，未调用麦克风采集。来源 App 禁止捕获、静音、系统权限限制时可能没有可听声音。

Android 系统要求使用者确认屏幕录制，停止授权后下次需重新确认。手机未在伴侣前台时不会直接发起新的屏幕录制，通知会提示返回确认。手机后台网页轮询、无人值守绕过系统录屏授权、同时捕获多个独立手机画面均不支持。

抖音可能要求登录、安全验证，或返回 HTTP 403／444／429。电脑会显示实际访问错误；请在专用浏览器手动完成验证，或使用手机抖音画面录制。没有绕过平台验证的实现。

源码构建手机包：安装 Java 21 与 Android SDK（平台 37、构建工具 36），运行 `python scripts/build_android.py`。Android 10 起可安装。签名私钥保存在开发机器 `.local`，更新安装须保留同一签名；私钥与配对密钥均不进入安装包。

参考：[Android 屏幕录制](https://developer.android.com/media/grow/media-projection)、[内部播放音频捕获](https://developer.android.com/media/platform/av-capture)。
