# 2.9.0 录播可靠性与手机界面

## 这次修了什么（对应你反馈的三件事）

**1. 录不了**

旧版本里，每位主播有两个设置：「检测开播的设备」和「录制设备」。列表里 7 位主播的检测设备都是「手机」，而电脑的调度只处理检测设备为「电脑」的主播（`integrations/live.py` 旧 `loop`）。结果是：电脑完全不检查这些主播，所有工作压到手机上；手机软件一旦退到后台、锁屏或被系统回收，就没有任何东西在检测和录制。这不是网络或平台问题，是调度条件把电脑排除掉了。

现在：

- 电脑始终负责检测开播，和「录制方式」无关，不再有「检测设备」这个选项。
- 把「录制方式」设为手机时，电脑解析出直播流地址后直接发给手机录制（手机不再依赖自己的 WebView 解析）。
- 手机 25 秒内没有回报真实写入字节，电脑立刻接手录制，不会因为手机没响应而漏掉整场。
- 只有真正写入磁盘的字节才算「录制中」，连接中/被拒绝不会显示成录制成功。

**2. 开播漏录**

- 检测间隔从「失败后等 5 分钟」改为 45 秒一轮（连续失败 120 秒）。
- 点「停止并保存」不再顺手关掉自动监控：只跳过当前这一场，主播重新开播还会自动录。
- 「关闭监控」仍然是独立开关，不会和「停止」混在一起。

**3. 手机按钮太多**

手机主界面只剩：主播列表（名称 + 当前状态 + 一个按钮）、底部三个入口（添加主播 / 回放 / 设置）。

- 添加主播：粘贴一次分享链接，昵称自动读取。
- 每个主播只有一个随状态变化的按钮（手机录这一路 / 停止并保存）。
- 电脑连接、USB 配对、手机自己检测、备用屏幕录制、诊断信息都收进「设置」。
- 开播检测和自动录制默认由电脑负责，手机不需要常驻前台。

## 另外修掉的一个真问题：回放列表被空任务淹掉

旧逻辑里，自动检测每次失败都会新建一个任务目录。实测 10 小时内积累了 **123 个空文件夹**（每约 5 分钟一个），工作台里全是「没录到」的卡片，真正录成功的反而找不到。

现在：自动检测如果一个字节都没录到，任务和空目录都不再保留（原因写在主播卡片的状态行，例如「未开播 · 检查于 14:52:10 · 开播后自动录制」）；手动点「开始录制」没录到时，任务会保留并说明原因。分段文件先登记再转封装，转封装失败也不会丢掉已经录到硬盘的 MKV。

## 验证边界

- 电脑端：上述真实抖音直播录制为实机证据（自动检测 → 录制 → 分段 → 保存 → 回放可解码、有音轨），直播间直链与主播主页链接两种入口都覆盖。
- 手机端：1.2.0（versionCode 5）在 vivo 真机上完成录制 → 停止 → 自动回传；1.2.1（versionCode 6）只多一个「哪台设备在录」的提示，需要手动确认安装（vivo 安装校验拦截静默安装）。
- 尚未覆盖：两路直播同时录制的并发压测；拔线后大文件续传的断点恢复。
- 本次验证期间用 `--home` 另开了独立实例，没有写入你的真实数据目录；测试产生的录像与解包目录已删除。

## 手机自己检测（1.3.0，2026-11-16 19:00 实机）

以前「手机自己检测（不用电脑）」只是把开关存进配置，代码里没有任何检测逻辑——假开关。1.3.0 补上了真的：

- 手机按主播列表逐个解析开播状态，一位查完自动下一位；单个主播超时 30 秒就放弃并推进，另有 90 秒看门狗强制跳过卡住的页面。
- 电脑在线时检测由电脑负责（省电），电脑断开 4 秒内手机自动接手。
- 抖音开播通知会立刻插队检查对应主播（已用 `cmd notification allow_listener` 授权 `LiveNoticeService`）。
- 录到的文件留在手机 `Android/data/org.videodesk.mobile/files/Movies`，回传电脑只是复制，原件保留。

**实机证据**（vivo 10ADA41UT7002GG，1.3.0 versionCode 8，电脑进程已停）：

| 时间 | 状态行 |
| --- | --- |
| 19:13:27 | 读取 胡说老王 的独立视频流 |
| 19:13:50 | 手机正在自行检测开播：车厘子 |
| 19:14:15 | 读取 车厘子 的独立视频流 |
| 19:14:39 | 车厘子：未取得可录制的视频流 → 自动推进下一位 |

**已知限制**：这几位主播用的是 `www.douyin.com/user/...` 主页链接。手机 WebView 没有登录态时，抖音对这些主页返回的是一段 JS 挑战页（实测 `live_status`/`ROUTER_DATA` 均为 0 次命中），30 秒内拿不到开播状态，于是手机自检测对这类链接只能算尽力而为。电脑端有持久化浏览器配置，主页链接实测能正常检测并起录（见上表）。所以可靠组合仍是「电脑检测 + 手机录制」，手机自检测作为电脑不在时的兜底。

**关于「录屏」**：手机录的是直播流本身（不需要系统授权、锁屏也能录），不是拍屏幕。要连弹幕/礼物一起拍成屏幕录像，Android 14 每次会话都必须人工点一次系统录屏授权，无法静默；需要的话再单独接无障碍自动点授权。
