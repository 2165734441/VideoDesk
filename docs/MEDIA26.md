# 2.6 使用说明

## 直播录播与回放

侧栏打开“直播录播与回放”，粘贴抖音直播间、主播主页或分享链接，每行一人。保存后可立即录制，或开启“开播后自动录制”。默认四路，可设置 1–8 路；实际数量受带宽、磁盘和平台访问状态限制。

定时监控采用北京时间。相同的开始、结束时间表示全天；例如周五 22:00–02:00 会录到周六 02:00。关闭网页不影响托盘服务，完全退出或电脑休眠期间不能录播。

录播优先原流保存，每 30 分钟一段，断线后重取地址续录并标记中断。完成片段可立即播放、拖动、倍速；浏览器不能解码时，停止该场录播后使用“生成兼容回放”。磁盘剩余不足 2 GB 时安全停止，不自动删除回放。强制断电留下的已登记片段会在下次启动恢复到回放列表，末尾可能需要兼容转换。

关注导入使用映格专用登录浏览器。先手动登录，打开自己的关注用户列表并滚动加载，再返回“读取关注列表”。仅导入网页实际返回的用户；无法确认完整时明确显示“未确认完整”。勾选主播添加后，需要自行开启监控。出现登录或验证页面时手动完成；软件不会替代平台验证。

## 英文视频转中文

1. 在“英文视频转中文”选择 AI 组件保存目录，安装 CPU 或 NVIDIA 运行组件及模型。可指向已安装组件的根目录；该目录应包含 `translation-runtime` 和 `translation-models`。
2. 选择一个或多个本地视频，也可从录播页面把某一片段交给翻译。外部字幕支持 SRT、VTT、JSON，必须与单个视频时间对应。
3. 默认先显示双语字幕，检查修改中文后点击“保存字幕并生成中文视频”。取消勾选“先检查”可连续生成。
4. 配音采用统一中文女声，尽量按原片时间安排；长于可用空隙的句子暂停等待缩短译文，不截断声音。背景声分离会增加耗时，可能残留英文或损失部分背景声；关闭后输出只保留中文配音。
5. 成品是 H.264/AAC MP4，英文在中文上方，另附英文和中文字幕、ASS、译文 JSON 及处理耗时。不会修改原视频、克隆人物声音或修改口型。原画面已有文字会保留，字幕位置可调整。

CPU 组件安装前至少预留 5 GB，NVIDIA 组件至少预留 20 GB（含安装临时空间），模型和后续处理还需磁盘空间。程序主安装包不内置这些大模型。模型包可导出、校验后离线导入；目标电脑仍需准备 AI 运行组件。

默认离线模型：Whisper small.en、OPUS-MT en-zh、Melo 中文声音、HTDemucs。具体版本、提交、哈希和依赖锁文件随源码提供。模型翻译可能存在语境和专有名词错误，可修改中文或自行配置兼容云服务提高适用性。

云服务分别配置基础地址、模型、密钥及声音 ID，支持 `/audio/transcriptions` 的带时间码转写、`/chat/completions` 翻译、`/audio/speech` 的 WAV 配音。只有选择云模式才发送内容，本地失败不自动上传。密钥保存在本机凭据目录，接口不回显；不会放入任务、模型导出或源码包。

## 加速与故障恢复

设备选择“自动”时，短于 30 秒的 AI 处理优先 CPU，以避免 CUDA 初始化得不偿失；较长视频有可用 GPU 组件时启用 CUDA。中文声音合成仍使用 CPU。视频编码先实际试运行，再选择 NVENC、QSV 或 AMF，失败回退 libx264。奇数宽高的旧分段导出继续用 CPU，保留原尺寸。

多人录播与离线翻译分别排队，翻译同时运行一个重型 AI 阶段。发生错误、取消或程序退出后，双语字幕和已完成片段保留，可重试；原视频 SHA256 变化时拒绝沿用旧任务。

## 当前验收边界

本地模型端到端、实际 CUDA/NVENC、四路本地 HTTP 录制、回放、字幕编辑和原有回归已测试。抖音真实房间、真实账号关注导入、付费云服务、AMD/Intel 设备仍需对应环境验收；这些项目不计作通过。详见根目录测试报告。
