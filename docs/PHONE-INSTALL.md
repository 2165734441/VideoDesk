# 手机伴侣：安装与连接（Android 1.3.5）

手机伴侣用来做「博主直播自动录制」：手机自己检测开播、自己把直播流录下来，录完通过 USB 自动把回放传回电脑。

它必须和电脑端配合：电脑端负责下发主播列表和开始／停止命令、接收回放。所以装好 App 只是第一步，**USB 连接正确才能用**。

## 一、安装

系统要求：**Android 10（API 29）及以上**。

安装包两种拿法，任选其一：

| 方式 | 做法 |
| --- | --- |
| 仓库直接下载 | 下载 [mobile/VideoDesk-Mobile.apk](../mobile/VideoDesk-Mobile.apk)（约 53 KB，版本 1.3.5 / versionCode 13） |
| 电脑端推送 | 电脑打开工作台 →「直播录播与回放」→「手机伴侣」→ 点**安装／更新手机软件**，程序通过 USB 把安装包推到手机 |

手动安装步骤：

1. 把 APK 传到手机（USB 拷贝、聊天软件传文件、或手机浏览器直接下载都可以）。
2. 点击安装。首次会提示「禁止安装未知应用」，到 **设置 → 应用 → 特殊权限 → 安装未知应用**，给当前使用的文件管理器或浏览器授权，再回来点安装。
3. 装完打开「映格手机伴侣」。
4. 首次打开会申请**通知权限**，建议允许：开播检测、录制状态、传输进度都靠通知提示，拒绝后功能仍然可用，但锁屏时更容易被系统清理掉。

升级说明：

- 直接覆盖安装即可，手机上的主播列表和已录文件不会被清空。
- 如果安装被系统**直接拒绝而且没有弹窗**，通常是版本号没有提高（同 versionCode 不允许覆盖）。安装更高 versionCode 的 APK 即可，不需要先卸载。
- vivo / iQOO 等机型的应用商店会抢安装弹窗，装的时候如果一直不出现安装页面，先退出应用商店再试。

## 二、连接电脑（这一步决定能不能用）

**两个开关缺一不可。** 少任何一个，App 都只会显示「电脑未连接」，博主直播自动录制不会启动。

### 1. 打开 USB 调试

- 设置 → 关于手机 → 连续点击**版本号** 7 次，提示「已进入开发者模式」
- 返回 设置 → 系统 → **开发者选项** → 打开 **USB 调试**
- vivo / iQOO：设置 → 系统管理 → 关于手机 → 版本信息，连点「软件版本号」；开发者选项在 设置 → 系统管理 → 开发者选项

### 2. USB 连接方式选「传输文件 / 管理文件」

插上数据线后，下拉通知栏点「正在通过 USB 充电」这条通知，把模式改成：

- **传输文件**（部分机型写「管理文件」或「MTP」）

**不要停在「仅充电」。** 这个模式下电脑识别不到手机，命令行看不到设备，App 也就永远连不上电脑——这是「电脑未连接」最常见的原因。

### 3. 允许调试授权

电脑端发起连接时，手机会弹出「允许 USB 调试吗」，勾选**一律允许使用这台计算机进行调试**，点确定。

### 4. 在电脑端连接

工作台 →「直播录播与回放」→「手机伴侣」→ 点**连接已安装的手机**。

连接成功后：

- 手机 App 顶部显示 **● 电脑已连接**
- 显示「已和电脑同步 N 位主播」
- 底部提示「共 N 位主播 · 列表可上下滑动」

### 连不上时的排查顺序

1. USB 模式是不是还停在「仅充电」——先改这个，八成的连接问题在这里
2. 开发者选项里的 USB 调试是不是打开的
3. 拔插数据线，在手机 App 的「设置」里点**与电脑重新连接 / 同步主播**
4. 换一根数据线或换一个 USB 口：很多线只能充电，没有数据线芯
5. 电脑端「手机伴侣」区域看提示是否会变成「已检测到 USB 手机」；停在「请连接手机并允许 USB 调试」说明系统层面就没认出设备，需要装厂商 USB 驱动
6. 用的是无线连接时，电脑端重启后原通道会失效，重新点一次连接即可

## 三、手机端自动录制怎么用

1. 连上电脑后，主播列表与电脑同步；也可以在手机直接新增主播（粘贴直播间链接或主播主页链接）。
2. 打开底部**自动录播**开关：全天检测，检测到开播自动开始录制。
3. 主播卡片上可以选「手机录这一路」或「电脑录这一路」，都能在手机上点。
   - 电脑已经在录的主播，手机不会重复录同一路；
   - 手机中途接手时，电脑会在几秒内让出并保存已录部分，不会产出两份重复文件。
4. 录制文件保存在手机 `Movies/VideoDesk`，每 30 分钟保存一段 MP4。
5. 录完接上 USB，回放会自动传回电脑的回放列表，断点续传，手机原件保留不删除。

## 四、建议打开的权限

| 设置项 | 位置 | 作用 |
| --- | --- | --- |
| 通知 | 设置 → 应用 → 映格手机伴侣 → 通知 | 开播、录制、传输状态提示 |
| 后台高耗电 / 不受限制 | 设置 → 电池 → 后台耗电管理 | 锁屏后不被系统杀掉，录制不中断 |
| 自启动（可选） | 设置 → 应用 → 自启动 | 重启手机后仍能继续 |

关闭省电模式、允许后台运行，是长时间录制不掉线的关键。Android 15 以上对后台数据传输有累计 6 小时限制，到限会保存已录片段并结束服务，重新打开 App 即可继续。

## 五、常见现象对照

| 现象 | 处理 |
| --- | --- |
| 一直显示「电脑未连接」 | USB 模式改成「传输文件」；确认 USB 调试已开；App 设置里重新连接 |
| 电脑端提示「请连接手机并允许 USB 调试」 | 系统没识别到设备：换线、换口、装厂商驱动，或确认 USB 调试已授权 |
| 锁屏后停止录制 | 允许后台高耗电，关掉省电模式 |
| 安装被拒且无弹窗 | 同版本号不能覆盖，装更高 versionCode 的包 |
| 录制中途断流 | 自动重连最多 5 次，仍失败会保存已录片段 |
| 手机显示「自己检测中」 | 说明当前没连上电脑，App 退回了独立模式；按上面步骤重连后状态会同步 |

## 六、数据与权限说明

手机端只处理你自己添加的主播；录制内容保存在手机本机，传回电脑后才进入电脑素材库。手机与电脑之间的命令和传输只走 USB 建立的本地通道（`127.0.0.1:47631`），不经过外网。不开启屏幕录制权限时，只使用直接录制视频流的方式，不会录屏。
