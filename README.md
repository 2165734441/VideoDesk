# 映格 · VideoDesk

**Windows 本地视频处理工作台：多人直播录播与回放、英文视频中文配音和双语字幕、视频抽帧、AI 阅读资料包、网页采集与素材管理。** 当前开发版本 **2.6.0**，通过浏览器操作本机服务。新增功能及实测范围见 [2.6 使用说明](docs/MEDIA26.md) 和 [测试报告](MEDIA26-TEST-REPORT.md)。

部分功能建立在 B 站 UP 主 **[苍穹晓雷（UID：109659565）](https://space.bilibili.com/109659565)** 的项目基础上，感谢其公开分享。分镜相关源码来源为 [dsh-video-storyboard](https://github.com/SAOS-3624/dsh-video-storyboard)，原始版权、许可证与修改说明均保留。

## 能做什么

| 功能 | 具体用途 |
| --- | --- |
| **多人抖音直播录播与回放** | 手动直播间 / 主播主页 / 分享链接、主播列表、登录后读取关注列表、北京时间定时监控；默认最多四路并发，分段保存，断线重试，按主播和场次回放。需要平台当前页面能正常访问；真实抖音和关注导入仍需登录态验收，四路本地流已实测。 |
| **英文视频转中文** | 本机视频、批量视频或录播片段，英文识别、中文翻译、统一中文女声配音、背景声分离和上下双语字幕压制；可检查修改译文，导出 MP4、SRT、ASS。模型首次安装联网，之后可本地处理；可另配兼容云服务。 |
| **按步骤自动加速** | 试编码通过后使用 NVENC / QSV / AMF；支持 NVIDIA CUDA 识别、翻译及背景声分离，中文声音合成使用 CPU；没有可用显卡或运行库时回退 CPU。短视频自动避免 CUDA 启动开销，CPU 与显卡实测结果见报告。 |
| **视频抽帧** | 按每隔几秒、每秒几张、每隔 N 原始帧或每一帧提取图片；可设时间范围、画面裁剪、数量上限、图片去重、音轨、分段小视频和 ZIP。默认只导出图片，不启动语音或文字识别。 |
| **AI 看懂视频：生成阅读资料包** | 检测镜头和代表画面，生成编号分镜图、原片时间、台词、画面文字及必要的原尺寸细节图；必需资料集中在“一起上传给AI”，便于交给支持图片和文本的 AI 阅读。 |
| **字幕区域截图长图** | 对视频中已经画在画面上的字幕区域定时截图并拼成长图；支持框选区域、时间范围与采样设置，便于回看和整理台词。它和提取 TXT/SRT 是不同功能。 |
| **批量与分集处理** | 选择多个文件、整个文件夹及子文件夹，支持中文和带空格路径；按集保存，也能把多个视频的 AI 资料合成联合包，保留标题、集号及各自时间边界。合并的是资料，不拼接 MP4。 |
| **链接下载与平台采集** | 使用 yt-dlp 解析下载链接、提取可用字幕；可选 MediaCrawler 对接 B 站和抖音的指定视频、关键词或作者来源。实际支持情况取决于上游解析器、网络、登录与平台限制。 |
| **网页录制与截图** | 由你选择浏览器标签页或窗口，框选画面，录制浏览器允许共享的视频与声音，或按设定频率截图；支持暂停、继续和停止保存。 |
| **本地字幕与语音处理** | 优先使用导入字幕、平台字幕或嵌入字幕；可用本地 SenseVoice 转写中、英、日、韩、粤语，并用 OCR 识别画面文字。也可明确选择自己配置的 ASR 服务。 |
| **素材库与图片去重** | 预览、查找、重新导出和管理任务；照片/截图可按完全重复或相似度分组，选择保留项、导出去重副本、隔离及恢复。 |
| **任务恢复与清理** | 显示阶段、进度和可估计的剩余时间；支持取消、重试及复用已完成结果。清理前预览，保护原片和用户改动；Windows 回收失败时不改成永久删除。 |
| **性能档位、CLI 与 DSH** | 自动、低占用、均衡、高性能按本机资源调整处理线程；网页、命令行和 DSH 插件共用本地服务、任务和素材。 |

“AI 看懂视频”负责**准备资料**，不会自动调用大模型，也不会自动把视频或资料上传给聊天 AI。你需要将“一起上传给AI”文件夹里的必需文件交给自己选用的 AI。原视频、可选音轨等附加素材放在该文件夹外。

## 本地文件与数据

- 本机路径和系统文件选择器直接读取原文件。网页选择或拖入的文件按需分块读取，处理期间需要保留工作台页面；来源断开后可重新选择同一文件继续。
- 原视频只有在明确选择复制导入或导出原片等操作时才复制。在线来源支持缓存和直接读取两种模式，以界面实际选项为准。
- 登录资料、Cookie、服务密钥、任务记录和缓存保存在本机，不进入本仓库和 AI 阅读资料包。在线下载、模型安装及自行配置的远程 ASR 会产生相应网络请求。
- 网页录制的来源由你在浏览器授权对话框选择。登录和验证码由你手动完成；平台账号权限、内容状态和访问限制仍然适用。

## 开始使用

本次 GitHub 首发提供**源码、DSH 插件和源码安装包**。公开源码包不含运行时、ffprobe、浏览器或模型权重，安装时按固定来源获取。已有单文件构建方式见 [构建说明](docs/BUILD.md)。

在 Windows 10 / 11 x64 上安装 Python 3.12、Git、Node.js 22，以及 Edge / Chrome，然后：

```powershell
git clone https://github.com/2165734441/VideoDesk.git
cd VideoDesk
.\install.cmd
.\start.cmd
```

首次安装需要联网；完成后默认打开 `http://127.0.0.1:18966`。语音模型可在“账号与模型”中安装或导入离线包。源码版通过 `stop.cmd` 关闭后台。

详细操作、端口设置、CLI、DSH 与构建条件见 [docs/BUILD.md](docs/BUILD.md)。更完整的功能参数和版本沿革保存在 [操作说明与历史记录](docs/USAGE-HISTORY.md)，旧版本命令示例中的版本号应替换为实际版本。

## 使用边界

视频采样可能漏掉短暂动作或文字；OCR 和语音转写也可能出错。字幕区域截图可能遗漏采样间隔里的短字幕。实时网页录制受浏览器节流、共享音频支持和系统性能影响，精确逐帧处理应使用已有视频文件。

本软件处理你提供的本地文件、链接或浏览器共享内容；请确认自己拥有获取、处理及分享这些内容的权限。导出给 AI 的内容和识别结果需要自行核对。
