映格 Video Desk 2.5.0 —— Windows x64 合并版

本版：视频抽帧、AI 看懂视频、字幕区域截图长图各自保存设置。
抽帧默认只生成图片；AI 必需资料自动集中到“一起上传给AI”。
低占用、均衡、高性能和自动仅调整计算资源；不会减少采样或识别资料。
任务等待来源时可重选同一文件继续；取消后须手动重试。
素材库支持多选预览并回收生成文件，保留原片及新增、修改或共享文件。
实测范围及限制见 release 中的 WORKFLOWS25-TEST-REPORT.md。

发送给别人：VideoDesk-2.5.0-Windows-x64.exe 一个文件即可。
接收者双击，自动准备环境并打开本机网页，无需 Python、Git、Node.js、FFmpeg。
Windows 10 / 11 x64，建议预留至少 4 GB。默认无需管理员权限，不修改系统 PATH。

启动就绪后自动隐藏到系统托盘，不占任务栏最小化窗口。
双击托盘打开工作台，右键可打开保存目录、查看状态 / 日志、退出。
重复双击 EXE 复用服务。关闭状态窗口只隐藏，关闭网页不停止本机路径 / 在线任务；拖入和网页选取来源会等待重新选择。
录制必须保持采集页面打开；退出前先停止并保存录制，等待或取消其他任务。

操作：导入视频 → 分析与抽帧 → 查看分镜 / 台词 → 细看片段 → 导出 AI 分析包。
保留网页框选录制、定时截图、yt-dlp、MediaCrawler、全部规则抽帧和照片去重。
新增 dsh-video-storyboard 场景分镜、行打包、台词对齐、音量测量和字幕长图。
直接模式不保存视频，缓存模式便于反复细看。顶部可更改素材保存目录。

语音：设置 → 安装本地模型，约 155 MB，支持中、英、日、韩、粤语。
OCR 引擎和文字模型已内置。其他运行组件首次准备可离线，访问平台仍需联网。
离线转写可同时发送 SenseVoice-offline.tar.bz2，在设置填写其完整路径后导入。
语音识别可能听错，时间为近似句子范围；现成字幕通常更利于准确对齐。
兼容 ASR 服务只在使用者自行配置并选择后调用。

登录两种方式：专用浏览器手动登录 / 处理验证码；或导入 Netscape Cookie 文件。
遇到可识别的平台验证，任务暂停；手动处理后点击“已完成验证，继续”重新解析。
Cookie、密钥、浏览器资料不会进入 AI ZIP 或分享包。

命令行：VideoDesk-2.5.0-Windows-x64.exe --cli help
DSH 插件：dsh-video-desk-2.5.0.zip，安装说明在插件 README.md。

程序与运行资料：%LOCALAPPDATA%\VideoDesk
默认素材：当前用户“文档”中的“映格素材”，网页顶部可更改。
分析缓存位置与用量在设置中，可清理应用副本；保留原片与正式导出。
诊断日志：%LOCALAPPDATA%\VideoDesk\launcher.log

2.5.0 启动兼容修复：
已内置微软签名的 x64 Visual C++ 应用本地运行库，通常无需联网或管理员权限。
首次启动逐项检查基础服务、音视频、下载、浏览器、分镜、去重、OCR 与本地语音。
识别组件失败时工作台仍可启动；受影响功能和信息缺口会明确显示，不代表完整识别成功。
托盘 → 检测并修复，或设置 → 运行组件与修复；请先等待任务完成或取消任务。
修复从 EXE 内重建程序组件，不删除账号、模型、保存设置、历史任务和素材。
修复后自动打开新的本机地址，旧网页可关闭。首次修复需额外磁盘空间。
系统运行库仍异常时，启动器的“安装系统运行库”从微软官网下载并验证微软签名，
然后调用微软安装器。Windows 可能要求管理员授权；不会自动重启电脑。
失败可重试，取消授权仍保留当前可用功能；离线时可先使用已内置的应用运行库。
启动器 → 导出启动诊断。诊断包含组件退出码、系统及处理器信息，不含账号或素材。
诊断原文件：%LOCALAPPDATA%\VideoDesk\runtime-diagnostics.json。
命令行修复：VideoDesk-2.5.0-Windows-x64.exe --repair

2.1 批量操作：
在“分析与抽帧”选择本机来源，可多选文件、选文件夹、拖入或粘贴多行路径。
文件名的空格和逗号保留，左右双引号忽略；文件夹可包含子文件夹。
每个视频独立排队、保存、取消或重试，坏文件不影响其余视频。
网页来源处理时保留工作台；来源断开后到素材库“重新选择文件并继续”。

导出可独立勾选图片、音轨、拼图、台词、小视频，或点“仅…”快捷项。
去重默认不勾选；勾选后可选完全相同 / 保守 / 适中 / 宽松 / 自定义。
分段默认不勾选，开启后默认 10 秒；小视频与按段整理素材分别控制。
每个视频使用独立名称和短标识，最后不足一段的部分保留。
字幕提供原视频时间和片段内时间，可另外生成 ZIP。
连接断开先点“重连”，旧地址失效则从托盘重新打开工作台。
完整验收记录：BATCH-TEST-REPORT.md。
